# `gk-motion` (03-animated-infographics)

Animated Infographics & Carousels: rebuild reference infographic layouts in your brand palette and export 1080x1350 PNG and PDF carousel cards plus animated MP4 visuals.

- **Plugin Manifest:** [`.claude-plugin/plugin.json`](./.claude-plugin/plugin.json) ([Raw](https://raw.githubusercontent.com/madmancf/octomarketer-skills/main/plugins/03-animated-infographics/.claude-plugin/plugin.json))
- **Models:** **Claude Opus 5.5** (`claude-opus-5-5`) for strategy, voice, decks, and creative direction; **Claude Sonnet 5.5** (`claude-sonnet-5-5`, `high` effort) for diagnostics, daily drafts, and subagent runs.
